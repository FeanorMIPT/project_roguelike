в данном репозитории находится код на python который реализует что-то похожее на мобильную игру soul-knight(но, конечно,
несколько проще).
При каждом запуске игры генерируется уникальное подземелье, которое игроку предлагается исследовать, и выбраться,
заработав как можно больше монет.
Подземелье представляет собой сеть комнат, соединенных коридорами, бывают комнаты обычные, где есть враги и ловушки, а
также бонусные, где есть сундук, позволяющий игроку восстановить здоровье и энергию
Каждая обычная комната состоит из разрушаемых и неразрушаемых препятствий, ловушек и точек возрождения врагов, причем
чтобы выйти из комнаты, игрок обязан победить всех врагов. Он может сделать это используя ближний бой или дистанционную
атаку. При этом враги также могут стрелять по игроку. Цель игры - выбраться из подземелья, при этом от аккуратности
прохождения игры и количества убитых врагов зависит количество монет которые игрок получит в конце игры - нужно собрать
как можно больше!
